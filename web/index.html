Supports PS2 memory-card images (.ps2 .mc2 .mcd .bin), .psu, and standalone .cbs .xps .sps.

🔒 100% offline & private. This page has no server; the file is read into memory here and the edited copy is saved straight back to you. Your original file is never touched.

ISO editing needs a desktop browser
The disc editor writes changed bytes back into your ~4 GB ISO in place, which needs the File System Access API — available in desktop Chrome / Edge / Brave / Opera. It isn't available in this browser, so the ISO editor is disabled here.

The Save editor works everywhere, including this device — switch to the Save tab above. On desktop you can also export a .s5mod recipe and share it.
Open a Suikoden V ISO
Choose your Suikoden V disc image
USA SLUS-21291 or PAL SLES-54087. Only a ~6.6 MB slice is read; on save, only the bytes you changed are written back in place.

🔒 Nothing is uploaded. Edits apply to a new game — do not use emulator save-states. Back up your ISO (or export a recipe) before saving.

No changes
Edits verified fields only. Suikoden V saves have no body checksum, so verified-field edits load in-game. Runs this repo's own Editor/s5save.py + s5patch.py unchanged in Pyodide — no upload, no install required.
