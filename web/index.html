Getting ready

Loading the Python engine (Pyodide)… first load fetches a few MB; later loads are instant and work offline.

Full save editor — hero/castle/army name, potch, party SP, active party, New Game Plus, and per-character level, equipment, runes, skills and recruitment. Everything runs in your browser via Python (Pyodide); your save never leaves the device. Works on desktop and Android. A backup is always wise.

Supports PS2 memory-card images (.ps2 .mc2 .mcd .bin), .psu, and standalone .cbs .xps .sps.

🔒 100% offline & private. This page has no server; the file is read into memory here and the edited copy is saved straight back to you. Your original file is never touched.

Edit the game disc directly — characters, gear, equipment sets, spells, full rune editing, prices, enemies, unites, MP growth, skill effects and more; nothing is uploaded. On desktop Chromium edits are written in place; on Android/Firefox/Safari you can still open, edit and export a .s5mod recipe. Back up first (or export a recipe).

Open a Suikoden V ISO

Choose your Suikoden V disc image
USA SLUS-21291 or PAL SLES-54087. Only a ~6.6 MB slice is read; on save, only the bytes you changed are written back in place.

⚠ This browser can't write the 4 GB ISO in place — you can still open, edit, and export a .s5mod recipe to apply on desktop Chrome/Edge/Brave/Opera.

🔒 Nothing is uploaded. Edits apply to a new game — do not use emulator save-states.
