Supports PS2 memory-card images (.ps2 .mc2 .mcd .bin), .psu, and standalone .cbs .xps .sps.

🔒 100% offline & private. This page has no server; the file is read into memory here and the edited copy is downloaded straight back to you. Your original file is never touched.

Edits verified fields only (hero/castle name, New Game Plus, per-character level, equipment, runes, skills, recruitment). Suikoden V saves have no body checksum, so verified-field edits load in-game. Keep your original file until you confirm the edited save loads.
Runs this repo's own Editor/s5save.py unchanged in Pyodide — no upload, no install required.
